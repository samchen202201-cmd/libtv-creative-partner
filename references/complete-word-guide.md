# 剧本确定后的完整 Word 制作指南

模块选择与共同协作方式见 [Skill 入口](../SKILL.md)。本模块规定完整交付的触发与内容，不另设创作审批流程。

## 1. 何时直接交完整指南

- 用户已经看过完整剧本，并明确表示采用、定稿或按此制作：直接整理并交付完整 Word 指南，不再问“要不要分镜”“是否继续准备资产”。
- 用户自带明确为定稿的剧本，并请求继续制作、下一步或完整方案：从该剧本直接交完整指南，不重新提案或改写故事。
- 用户一开始就明确授权自主完成整套方案：在本次委托范围内完成剧本与指南，不为了取得一次“确认剧本”而新增等待关卡。
- 用户只认可一个题材或一句话故事：先按请求写出剧本，不把选择故事方向误当成确认完整剧本。
- 用户明确只要某个镜头、某类资产、局部修改，或明确指定其他格式、暂不继续：这些要求优先，不自动附整套指南。

普通创作细节由模型合理补足。只有会改变已确定核心剧情、角色身份或用户明确要求的关键歧义才简短询问，不把时长、镜头数、每项资产都变成确认点。

## 2. 交付是一份真实文件

默认生成一份可打开的 `.docx`，完整收纳从剧本到视频制作所需的信息。聊天里给文件链接和简短内容说明，不把正文刷成长消息，也不让用户自行复制聊天记录拼成文档。

实际生成文件时，存在 `documents` Skill 就按其要求使用；默认由本包 [Word 生成器](word-builder.md) 配合 `assets/production-guide.docx` 排版，不每次重新开发生成程序。内容稿独立编写，排版时不改剧情。用户提供自己的模板时优先按其模板制作。生成器只依赖 Python 3 与 python-docx，不使用私人目录或外部接口。用户明确要求旧版二进制 `.doc` 时才进行真实格式转换；格式未转换就保留真实扩展名，不靠重命名伪装。

文档用清晰的中文标题层级和可导航目录，正文可选中复制。分镜与资产概览用紧凑表格；长 Prompt 放在独立小标题下的正文段落，不挤进超宽表格或固定高度文本框，不把文字做成图片。平台说明、参考前提与可复制正文分开排版。

用户已经确定的完整剧本必须收入正文，不只留下摘要或“见原文件”。分镜、资产及提示词也不放到必须另行打开的附件中。可以复用同一资产，不要求用户拼接多份文档才能开始制作。

默认按“项目速览 → 完整剧本 → 分类资产 → 全片时间轴 → 逐镜执行 → 声音与文字后期 → 制作顺序”组织。首页直接交代故事钩子、观看感受、视听变化和先做哪些资产，不用独占整页的装饰封面。时长、镜头数和页数随作品需要，不套用样片数值。

### 文档生成条件缺失时的应急交付

先检查当前可用的文档工具、现有 Python／python-docx 与可写输出目录；只有实际缺失或调用失败时才进入应急分支，不因担心依赖就预先降低交付格式，也不自动安装依赖或变更权限。

- 若仍可写文本文件，保存完整 Markdown 内容稿并给出链接；仅能聊天时，将同样完整的正文在对话中交付。章节、剧本、资产和 Prompt 保留，不用摘要替代；篇幅需要分段时明确已交部分与剩余部分，不把半份正文说成完整交付。
- 明确说明“完整正文已交付，Word 尚未导出”，同时给出真实失败原因和恢复导出的必要条件。Markdown 是应急内容，不是成功导出的 Word，也不承诺无人触发的后台补交。
- 用户明确只接受 Word 或拒绝聊天正文时，优先遵守：保留可保存的内容稿，说明当前缺项与 Word 未完成状态，不擅自替换最终格式或刷长篇正文。
- 条件恢复且用户继续任务时，复用已有内容稿导出，不重新写剧本。文件链接以生成器实际返回的路径为准，同名输出递增保留原稿，详见 [生成器说明](word-builder.md)。

### 开篇提示：在 Codex 中一条指令启动生图

在制作概览附近加入一则简短、可复制的提示，不把选择生图方式变成文档交付前的问题：

> **想直接生成图片？** 在支持生图的环境中，本指南里的角色、场景、道具、风格参考，以及分镜真正需要的动作首帧和目标尾帧图，可以在同一次静态资产任务中按参考依赖生成。留在当前任务发送下方指令即可；新开任务时，请附上这份指南。也可以只指定某个角色、场景或镜号。生图会消耗当前环境的使用额度并需要等待，音频与视频另行制作。

> 请按这份指南，在 Codex 中生成全部需要的静态视觉资产，包括角色、场景、道具、风格参考，以及指南判定需要的动作首帧和目标尾帧图。复用已有满意素材，默认质量优先；先准备共用参考，再生成依赖它们的帧图，分别保存为独立图片，并注明镜号／片段与参考用途。视觉概念图不要自动当作视频首帧锁定构图；本次只生成图片。

“一键生成”指一条自然语言指令启动，不虚构可点击按钮、即时完成或一次成功的承诺。完整指南与全部 Prompt 先交齐，不等待生图，不自动调用图片、音频或视频生成。若当前环境的生图能力未核实，保留“在支持生图的环境中”的条件表述。

用户之后明确要求生图时，按指定范围调用当前可用的内置生图工具；存在 `imagegen` Skill 时读取并遵循。确认剧情或收到指南不等于要求生图，本文示例也不是执行指令。明确委托整套静态资产时，按参考依赖推进，不逐张重复确认；只在影响核心设计的歧义或真实阻塞处询问。保留满意参考，检查明显身份与空间漂移，保存独立图片及名称／镜号对应，不把图只嵌在 Word 中。工具未提供或执行失败时如实说明，不默默转向外部 API、上传素材或替用户购买额度。

## 3. 正文必须覆盖的内容

按作品实际需要填入完整内容，不把以下清单原样作为空模板交付。不相关的类别简短说明不需要或省略，不为凑齐清单凭空增加人物、对白、道具或音乐。

### A. 制作概览与完整剧本

- 片名、作品形式、目标时长与画幅；区分用户已定条件与合理建议。
- 收入用户确认的完整剧本，保留剧情、对白、人物关系和结局。可整理聊天式换行，但不压缩成梗概、不漏对白。制作性补充另行说明，不借编导加工暗改故事。
- 概述全片导演意图：观众何时知道什么、情绪怎样变化、表演尺度、构图与运动、色彩材质、主要光影和声音策略。把“电影感”等抽象词落到具体可见、可听的设计。

### B. 全片分镜表

每个镜头有稳定镜号，能对应剧本的场次或情节。时间轴表用于总览，紧凑呈现计划时段与时长、景别机位和运动、主要动作与本镜作用；详细表演、光影、对白、声音与衔接放到对应的逐镜执行节，避免在多列表格里反复塞入长段文字。

计划时长与全片目标应基本吻合，给对白、呼吸及反应留出空间；明确这是制作计划，不是已生成或实测的成片时长。区分剪辑镜头和独立生成片段，需要拆分生成时写清对应关系，不为适配假定的固定时长机械切镜。

收尾的关键动作与情绪反应也需要时间。单镜承载过多事件时，重新分配节奏或拆分镜头，不用删对白、倍速或省略动作来硬凑目标时长。

### C. 视觉资产清单与逐项生成 Prompt

概览中写清资产名称、用途、适用镜头、已有素材的保留方式，以及要补的视角或状态。角色、场景、道具和风格 Prompt 在本章逐项给出；动作首尾帧在资产表登记用途与依赖，完整单图 Prompt 集中在 D 节对应镜头，不重复抄录。

按 [资产模块](assets-sound.md) 区分“出场实体”和“需要独立准备的素材”，覆盖短暂但关键的证据与非人主体。角色变体、场景日夜和道具前后状态关联到同一底稿，在现有用途栏写明场次／镜号，多集再写集数；不为背景陈设逐项另建生成任务，也不新增频次审批表。

- **角色及特殊主体：**按 [资产模块的人物底稿](assets-sound.md) 先整理主要人物小传与特征描述，再给身份外观、实际用到的形态、服装与状态变化及可复制 Prompt。小传说明身份、有关经历、目标、关系和行为依据；外形、造型、表演与声音分开。次要角色按作用简写，不凭空补故事。按镜头需要准备面部、全身、背面或关键表演参考。
- **场景：**空间布局、行动路线、固定地标、日夜天气与光源；需要反打或换方位时给出对应参考生成说明。
- **道具：**辨识特征、材质尺度、关键结构、接触方式，以及剧情实际用到的开合、交接、损坏等状态。
- **风格参考：**全片确实需要的造型、材质、光色参考及其用途，不以万能“高质量”后缀代替设计。
- **动作首尾帧图：**按 [资产模块](assets-sound.md) 的职责判断，登记镜号／片段、名称、用途、依赖及已有素材的复用方式。用户指定的范围优先；每张独立保存，完整单图 Prompt 只放到下方对应逐镜节，不把清单中列名当作已绑定或已生成。

已选素材不重复要求从零生成；为必要的新资产和衍生状态写足指令。未提供任何参考时，也给出能先生成基础资产的自足文字，不只写“待补角色图”。资产名称可以用于制作识别，但不冒充真实文件名、已存在节点或平台自动绑定语法。

独立使用的关键物件分别指认，不把互不相关的道具混成一张难以引用的图。交接或状态变化写清起止归属；反向场景延续同一空间布局，不以简单镜像代替真实反打。剧情文字的内容、出现位置和后期添加方式列入声音与文字章节。

需要新建完整人物参考时，采用 [资产模块](assets-sound.md) 的角色定妆三联模板：左侧清晰正面特写、中间遮脸全身正面、右侧全身背面。把按本角色填好的完整 Prompt 写入本文，不只给模板链接。说明左侧负责面部身份、正背面负责体型服装；遮挡仅用于参考排版，不带入分镜关键帧或视频。已有合适参考不强制重排，侧面图仅按实际镜头需求另补。

人物小传、可见特征、参考分工与相应 Prompt 放在同一角色条目下，读者不必自己把小传改写成提示词。区分原稿事实与制作建议；有身份互换、伪装等情况时，补清剧情身份、实际外形参考和行为／音色的对应关系。剧本与旧分镜有冲突的设定不混入小传或定妆依据，只有影响当前制作的部分才请用户确认。

### D. 逐镜关键帧与视频 Prompt

每个镜头单独成节，按分镜顺序提供：

先用简短文字说明本镜任务、计划时长、表演与光影，并在同节列出完整对白及声音提示。读者不必来回翻页拼出本镜要做什么。

1. **输入与用途：**需要什么人物、场景、道具、构图或姿态参考；各自保留什么，冲突时以哪个特征为准。
2. **动作首帧与目标尾帧生成 Prompt：**按 [资产模块](assets-sound.md) 判定用途和依赖后，集中给出本片段真正需要的完整单图 Prompt，与 C 节名称对应。每张描述单一动作瞬间、构图、位置与视线、道具状态和光影；概念图不自动锁首帧，目标尾帧不冒充真实末帧。用户指定全套时给齐；各帧独立保存，不拼成对照图，不强制每个切镜都用尾帧续接。已有实际选定帧注明复用，不重生成已满意素材。
3. **视频生成 Prompt：**起始状态、行动与反应的过程、方向及接触、相机如何运动、结束状态，以及本次采用的声音处理。先做轻量运镜可执行性判断；对白、交接和身份镜头写准关键关系，高动态奇观优先保留清楚的运动主线、摄影机关系与节奏变化，不逐秒塞满限制。将分镜阶段设计好的动作接切、遮挡或甩镜等过程融入对应 Prompt，使前后片段能够接力，不只写“顺滑转场”。独立生成片段需要计时时从局部 0 秒开始；需要的可剪余量与正片计划时长分开。
   声音与字幕的制作目标按 [Prompt 模块](prompts-revisions.md) 执行：每镜默认无 BGM／无字幕并保留必要声音，按已核实模型入口决定正文、负向字段、设置与后期的分工。独立复制项自包含，不只在全局写一次，也不将不受支持的负向语法塞进所有模型。
4. **必要设置与连接前提：**生成方式、计划比例和时长等。按需提供英文正文及实际入口支持的独立字段，清楚标注粘贴位置；未核实字段不伪造。引用真实已有参考时按素材指认；尚待生成的输入写清先生成、选定，再连接的顺序，不声称已完成绑定。
5. **选片与衔接重点：**仅在需要时补一句具体拼接说明，写清在哪个动作、视线、遮挡或声音事件上切，以及是否去掉重叠动作。声桥和叠化等后期操作与可复制 Prompt 分开；不附逐镜评分表或额外衔接台账。

每条独立复制的 Prompt 都包含本次必需的信息；不以“同上”“沿用全局 Prompt”代替完整正文。有可靠参考时描述本次变化，避免每镜重复整张资产卡。若已有选定关键帧，给出复用或必要局部修改指令，不强迫重做满意图。

具体模型、槽位、时长范围、分辨率和音频输入以当前可核对能力为准。资料不足时明确列为执行时核对项，同时交齐创意内容和自然语言 Prompt；不编造按钮、参数或功能，也不因此删减关键剧情、动作或视效。

### E. 声音制作资料与 Prompt

- **音色：**每个有声角色的声音身份、语言口音及必要参考说明。没有对白或人声的作品不凭空新增配音任务。
- **逐句对白与表演：**原台词、说话人、对应镜头、说话对象、表演意图、停顿重音和必要呼吸。台词正文与表演指令分开，避免把指令念出来；给出可复制的配音生成内容。
- **独立 BGM 资产：**各段的情绪发展、配器与节奏、进入退出位置、与对白的主次关系，并给出供 LibTV 独立音乐生成使用的各项音乐 Prompt；不附视频的“不要 BGM”要求，不只留一句“后期配乐”。
- **环境、拟音和效果声：**按实际所需声源或事件给出生成 Prompt、触发镜头、远近及连续性，不只写“加合适音效”。
- BGM 默认独立准备并在后期加入；对白、环境声与动作音效按设计说明随视频生成或独立准备，避免重复叠加。需要声音先入或延续时，写清源镜、目标镜和触发事件；跨镜对白保留同一句连续表演，不让相邻片段重新起句。实际声桥与混音在后期完成。未知的轨道分离能力不写成已具备；已有录音时用实际时长，没有时只做估时。

### F. 从资产到成片的操作指南

按照本文内容给出用户能照做的制作顺序，而不是再讲一遍通用行业 SOP：

1. 准备并选定共用角色、场景、道具和风格参考；指出先后依赖及可并行准备的部分。
2. 在同一次静态资产委托中，依据已准备的共用参考生成或复用经判断需要的动作首帧和目标尾帧，分别保存并对应镜号／生成片段；视觉概念参考单独标明职责。用户随后要求生成视频时，再核对模型支持的输入方式，使用本镜视频 Prompt；复杂动作采用适合的关键帧、分段或后期方法，不默认牺牲效果。
3. 从结果中保留叙事动作与状态正确的片段。需要续接时使用用户选定帧，保持身份、姿态、视线、道具和光向；换场或跳时不强制尾帧续接。
4. 按分镜及逐镜拼接说明完成粗剪，依据实际动作、对白和反应选切点，去掉动作重叠、不可用头尾或多余停顿；按设计处理声音先入、延续、留白或转场。不因为预先写过过渡 Prompt 就跳过实际拼接检查。
5. 将独立准备的 BGM 加入剪辑，平衡对白、环境、拟音与音乐；本片需要字幕时在后期添加，并处理片头片尾及剧情内画面文字。关键文字可安排后期叠加，不寄望生成画面自动正确写字。
6. 按实际发布用途给出画幅、输出清晰度、帧率和导出建议；区分建议与已验证的软件设置，不把生成分辨率等同于最终画质。导出后检查声音、文字和首尾是否完整。

步骤与本文件里的镜号、资产和 Prompt 对得上，不让用户再次询问“下一步复制哪段”。实际上传、运行生成、声音克隆、付费与发布仍需对应授权；交付指南本身不执行这些动作。

## 4. 交付前的轻量检查

在生成文档过程中检查明显缺项和矛盾，不展开重型 QA 或多轮创作竞赛：

- 完整剧本、分镜、资产、逐镜关键帧和视频 Prompt、必要声音资料及制作步骤均已写入；镜号和名称对得上，没有把必需内容留到“下一步再给”。
- 已确定剧情和台词未被擅改；必要状态变化有资产或镜头支持；相邻镜头没有意外重做动作或改变道具归属。Prompt 可独立复制，生成内容与后期拼接说明分开，未知设置与待生成素材没有冒充已核实或已完成。
- 文件真实存在且是有效 Word 文档；检查正文完整、中文可读、表格和长 Prompt 没有明显溢出或截断。有渲染能力时检查实际版面；未做视觉检查就不宣称排版已完整验证。

### 最终回复：文件链接与三行速览

提供真实文件链接，下面用三行帮助用户开始：

> 作品：《片名》｜计划时长｜题材。  
> 内容：实际镜头数｜主要资产及数量｜声音与剪辑资料。  
> 下一步：在支持生图的环境中发送“请按这份指南生成所需静态视觉资产，保留已有满意素材；本次只生成图片。”

填入本文实际内容，不强凑统计；需要时区分镜头数与生成片段数。时长写明是计划或实测，展示指令不自动启动生图。未核实生图能力时保留条件表述；用户只需其他任务时给对应下一步。应急交付明确 Word 尚未导出，不提供不存在的 Word 链接。

区分“制作指南已交付”与“媒体已生成、成片已验证”，不附研发过程、模型比较、私人来源路径或画布源节点记录。
